CAMPUS EVENTS HUB - MISHKAT VERSION

Organization: Mishkat Student Programs Center
Team: Abdulaziz alsuriay; Mohammed Alsubaie; Ibrahim Alyahiwi

SETUP
1. Copy mishkat-campus-events to C:\xampp\htdocs\
2. Start Apache and MySQL.
3. Open http://localhost/phpmyadmin and import database.sql.
4. Open http://localhost/mishkat-campus-events/

DATABASE
Host: localhost
Username: root
Password: empty
Database: mishkat_campus_hub
Connection file: includes/db.php

PAGES
index.php, events.php, event.php, register.php, registrations.php, about.php

The contact form validates but does not send or store messages. The registrations page is public for academic demonstration.
